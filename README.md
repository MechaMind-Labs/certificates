# MechaMind Labs · certificate verification

Public verify page for MechaMind Labs Certificates of Completion: **https://mechamind-labs.github.io/certificates/**

- Open `https://mechamind-labs.github.io/certificates/?id=<CERTIFICATE-ID>`, or scan the QR code printed on the certificate.
- A certificate can only be looked up by its **full ID**. There is no public list of certificates, and IDs end in five random characters, so they cannot be guessed. A certificate is visible only to the people its holder shares the ID with.
- A lookup returns only the public fields of that one certificate: ID, name (or initials, by the learner's choice), course, track, result, issue date, project link (with consent), status and related certificate. It never returns emails, scores or review notes.
- Certificates are issued only after a manual review of practical work. How AMR Mastery certification works: [CERTIFICATION.md](https://github.com/MechaMind-Labs/AMR-Mastery/blob/main/CERTIFICATION.md).

Certificate IDs: `MML-AMR-SIM-YYYY-NNNN-XXXXX` (AMR Mastery, Simulation Track) and `MML-AMR-HW-YYYY-NNNN-XXXXX` (AMR Mastery, Hardware Track).
